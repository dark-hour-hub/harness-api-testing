# 模块接口文档模板

每个接口严格遵循以下四级标题结构，逐接口独立成段，禁止摘要表格和折叠形式。

---

## 文件头模板

```markdown
# {模块名称} API 文档

> Controller: `{ControllerClassName}` | Base URL: `{base_url}` | Auth: Sa-Token JWT `Authorization: Bearer {token}` + `clientid: {value}`

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式；文件上传使用 `multipart/form-data` |
| Authorization | `Bearer {token}` | Sa-Token JWT 令牌，登录后获取 |
| clientid | `{value}` | 客户端 ID，与 Token 绑定 |
```

## 段落规则

### 路径参数表

有 `@PathVariable` 时展示：

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|:---:|------|------|
| `{name}` | {Type} | 是 | {说明} | `{example}` |

### 查询参数表

GET 分页接口必须穷举 PageQuery 字段 + Bo 全部可查询字段（排除 @JsonIgnore），每个字段标注匹配方式：

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `pageNum` | Integer | 否 | — | 当前页码，默认 1 | `1` |
| `pageSize` | Integer | 否 | — | 每页条数，默认 10 | `10` |
| `orderByColumn` | String | 否 | — | 排序列名 | `"createTime"` |
| `isAsc` | String | 否 | — | 升序/降序 (asc/desc) | `"desc"` |
| `{field}` | {Type} | 否 | {eq/like/between/in} | {说明} | `{example}` |

匹配方式映射：`eq`=精确匹配, `like`=模糊匹配, `between`=区间匹配(配合 params), `in`=IN 查询

### 请求体

- 有实体文件 → `[{ClassName}](../entities/{ClassName}.md)` 引用，不内联字段
- 无实体文件 → 展开完整字段表 + JSON 示例
- MultipartFile → 标注 `Content-Type: multipart/form-data`，说明参数名

### 成功响应

- 有实体文件 → `[{ClassName}](../entities/{ClassName}.md)` 引用 + JSON 示例
- 无实体文件 → 展开完整字段表 + JSON 示例
- 返回 void / 二进制流 → 描述响应行为（如"直接返回文件流"）

### 错误响应

必须追踪三层，i18n key 必须尝试解析：

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 200 | 200 | 操作成功 | `"操作成功"` |
| 401 | 401 | Token 缺失或失效 | `"认证失败，无法访问系统资源"` |
| 403 | 403 | 权限不足 | `"没有访问权限，请联系管理员授权"` |
| 200 | 500 | {DTO 校验失败} | `"{解析后的实际消息}"` |
| 200 | 500 | {Service 层业务异常} | `"{解析后的实际消息}"` |
| 200 | 601 | {警告场景（如删除受限）} | `"{解析后的实际消息}"` |

i18n 解析优先级：
1. 校验注解 `message="{key}"` → 查 `**/resources/**/messages*.properties`
2. `MessageUtils.message("key")` → 同上
3. 硬编码字符串 → 直接使用
4. 找不到翻译 → 保留原始 key，标注 `(i18n key, 未找到翻译)`
