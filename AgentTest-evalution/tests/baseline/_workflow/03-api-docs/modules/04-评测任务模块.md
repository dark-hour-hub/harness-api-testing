# 评测任务模块 API 文档

> Controller: `EvaluationTaskController` / `EvaluationExecutionController` / `IndicatorMeasurementController` / `EvaluationResultController` | Base URL: `http://localhost:8080` | Auth: 无（auth_type: none，所有接口公开访问）

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式（本模块无文件上传） |
| X-Trace-Id | `{自定义字符串}` | 可选，链路追踪 ID（TraceIdFilter 透传并回写响应头）；缺失时服务端生成 32 位十六进制 UUID，永不因缺失报错 |

> 认证说明：全项目无任何认证机制，无 `Authorization`/`clientid` 等鉴权头，无权限模型。本模块覆盖任务生命周期：创建（CREATED）→ 启动执行（RUNNING，异步）→ 测量证据提交/确认 → 完成（COMPLETED/FAILED）→ 终评定稿（finalize）→ 结果/报告查询。
>
> 响应包装：所有接口响应体均为 [ApiResponse](../entities/ApiResponse.md)（code=`"200"`/message=`"success"` 表示成功）；分页数据为 [PageResult](../entities/PageResult.md)（items/page/pageSize/total，pageSize 上限 100）。本模块所有分页接口默认 `page=1`、`pageSize=20`。
>
> 错误响应统一由 `GlobalExceptionHandler` 处理：HTTP 状态码 = ErrorCode.httpStatus()，响应体 code = ErrorCode.name()，message = ErrorCode.defaultMessage()（硬编码，无 i18n）。本模块涉及的错误码：
>
> | code | HTTP | message |
> |------|:----:|---------|
> | COMMON_400_VALIDATION | 400 | `"Validation failed"` |
> | COMMON_404_RESOURCE | 404 | `"Resource not found"` |
> | COMMON_409_CONFLICT | 409 | `"Resource conflict"` |
> | AGENT_400_CONFIG | 400 | `"Invalid agent configuration"` |
> | SCHEME_400_INVALID | 400 | `"Invalid evaluation scheme"` |
> | TASK_409_SCHEME_STATUS | 409 | `"Evaluation scheme is not available for this task"` |
> | TASK_409_STATUS | 409 | `"Evaluation task status conflict"` |
> | TASK_409_SNAPSHOT_UNSUPPORTED | 409 | `"Evaluation task snapshot is not supported"` |
> | TASK_409_RESULT_NOT_READY | 409 | `"Evaluation result is not ready"` |
> | TASK_500_RESULT_INCONSISTENT | 500 | `"Persisted evaluation result is inconsistent"` |
> | TASK_503_EXECUTOR | 503 | `"Evaluation executor unavailable"` |
> | COMMON_500_INTERNAL | 500 | `"Internal server error"` |

### 1 创建评测任务

| 属性 | 值 |
|------|-----|
| **请求方式** | `POST` |
| **接口路径** | `/api/evaluation-tasks` |
| **接口说明** | 创建评测任务：快照 Agent + 已发布方案，仅落库不执行，任务状态 CREATED |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **标签** | tasks |

---

#### 请求

**请求头**: [公开]

无路径参数，无查询参数。

**请求体**: [CreateEvaluationTaskRequest](../entities/CreateEvaluationTaskRequest.md)

- `@Valid` 校验：`agentId`（@NotNull @Positive）、`schemeId`（@NotNull @Positive）必填；`createdBy` 可选（@Size(max=100)），空白时服务端默认 `"api"`
- 请求体 JSON 格式错误时由本 Controller 本地 `@ExceptionHandler(HttpMessageNotReadableException)` 返回 400

```json
{
  "agentId": 1,
  "schemeId": 1,
  "createdBy": "api"
}
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 400 | COMMON_400_VALIDATION | `agentId`/`schemeId` 缺失或非正数（@Valid 失败） | `"Validation failed"` |

#### 业务规则

| 规则 | 说明 |
|------|------|
| 快照语义 | Agent 与方案在创建时冻结为 agentSnapshot/schemeSnapshot，后续修改不影响本任务；同时计算 snapshotHash |
| 幂等/状态 | 创建即落库，`sourceType=SCHEME`，任务状态固定 CREATED，不触发任何执行 |
| 用例初始化 | 按方案冻结用例生成 EvaluationTaskCase 列表（PENDING、attemptCount=0、sequenceNo 按快照顺序） |
| createdBy | 请求头/请求体均无认证身份来源，`createdBy` 由前端可信传入，空白时默认 `"api"` |

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|

| 404 | COMMON_404_RESOURCE | Agent 不存在 | `"Resource not found"` |
| 400 | AGENT_400_CONFIG | Agent 未启用（enabled=false） | `"Invalid agent configuration"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 不保存方案 | 请求按来源配置内联构建 EvaluationScheme（状态 PUBLISHED）后冻结为快照，方案行不入库 |
| 目录版本 | `catalogVersion` 缺省时解析为唯一已发布版本（无版本服务时回退 `"V1"`） |
| 默认权重 | `dimensionWeights` 缺省时按风险等级 `riskTier` 取目录版本默认维度权重 |
| 必评语义 | `indicators[].required` 为 null 时按 bool 解析为 false，但冻结快照时与目录指标 `required()` 取或 |
| 来源校验 | 指标/用例必须完整命中所选目录版本，缺任一 ID 报 SCHEME_400_INVALID |
| 返回语义 | 成功返回轻量 CreateEvaluationTaskResponse（不同于接口 1 返回完整 EvaluationTask） |

### 3 分页查询评测任务列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/api/evaluation-tasks` |
| **接口说明** | 分页查询评测任务列表，支持状态过滤 |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **标签** | tasks |

---

#### 请求

**请求头**: [公开]

无路径参数，无请求体。

**查询参数表**（全部由 Controller 手工解析，类型声明为 String 但按下列规则转换）：

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `status` | String | 否 | eq | 任务状态精确过滤；合法值 `CREATED`/`RUNNING`/`COMPLETED`/`FAILED`；空白视为未传；非法值报 400 | `"RUNNING"` |
| `page` | String | 否 | — | 页码，从 1 开始，默认 `1`；小于 1 或非数字报 400 | `1` |
| `pageSize` | String | 否 | — | 每页条数，默认 `20`，范围 1~100；越界或非数字报 400 | `20` |

> 匹配方式映射：`eq`=精确匹配。
>
> 排序固定：`ORDER BY created_at DESC, id DESC`，无排序参数。
>
> 查询对象：`EvaluationTaskQuery(status, page, pageSize)`，仅 3 个字段，无其他过滤条件。

---

### 6 启动评测执行

| 属性 | 值 |
|------|-----|
| **请求方式** | `POST` |
| **接口路径** | `/api/evaluation-tasks/{id}/run` |
| **接口说明** | 启动评测执行（异步）：任务状态 CREATED→RUNNING，后台执行器逐用例调用智能体并评分 |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **标签** | tasks（EvaluationExecutionController） |
| **特殊属性** | HTTP 202 Accepted（异步接受，非同步完成） |

---

#### 请求

**请求头**: [公开]

**路径参数表**：

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|:---:|------|------|
| `id` | long | 是 | 任务 ID（原生 long 绑定，非 Controller 手解析）；非数字导致类型转换异常（走全局兜底返回 500）；<1 或不存在返回 404 | `1` |

无查询参数，无请求体。

#### 响应

##### 成功响应 — HTTP 202 Accepted

响应体：`ApiResponse<RunTaskResponse>`

- 外层包装：[ApiResponse](../entities/ApiResponse.md)
- data：[RunTaskResponse](../entities/RunTaskResponse.md)（字段与 EvaluationTaskProgress 一致，为提交瞬间的持久化进度：status=`RUNNING`、completedCount=0）

```json
{
  "code": "200",
  "message": "success",
  "data": {
    "taskId": 1,
    "status": "RUNNING",
    "progress": 0,
    "totalCount": 10,
    "completedCount": 0,
    "successCount": 0,
    "failureCount": 0
  },
  "traceId": "test-case-001"
}
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 404 | COMMON_404_RESOURCE | 任务不存在（含 id<1） | `"Resource not found"` |
| 409 | TASK_409_STATUS | 任务状态非 CREATED（已 RUNNING/COMPLETED/FAILED），或并发下 startIfCreated 抢占失败 | `"Evaluation task status conflict"` |
| 409 | TASK_409_SNAPSHOT_UNSUPPORTED | 任务快照缺失或维度列表为空 | `"Evaluation task snapshot is not supported"` |
| 503 | TASK_503_EXECUTOR | 执行器队列满（AbortPolicy 拒绝提交），任务被标记 FAILED/EXECUTOR_REJECTED | `"Evaluation executor unavailable"` |
| 500 | COMMON_500_INTERNAL | `id` 非数字（类型转换异常）等未预期异常 | `"Internal server error"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 异步行为 | **异步执行**：接口仅负责状态迁移与任务提交，202 立即返回；实际执行在 `evaluationExecutor` 线程池（1 线程 + 队列容量 100，AbortPolicy）后台运行，进程重启后由恢复器（InterruptedExecutionReconciler）衔接 |
| 执行流程 | TaskExecutionCoordinator 按 sequenceNo 顺序逐用例执行：begin → 调用智能体（多轮按轮次记录）→ complete 判定；普通调用失败跳过该用例继续，致命配置失败则整体 FAILED |
| 状态机 | 仅 CREATED 可启动；提交成功任务置 RUNNING 并记录 startedAt；全部用例终态后评分并置 COMPLETED；异常路径置 FAILED 并写 interruptionReason |
| 完成阶段 | 评分组件不可用（ExecutionCompletionUnavailableException）时任务标记 FAILED/SCORING_COMPONENT_UNAVAILABLE，可由 finalize 接口基于已确认证据重算 |
| 返回进度 | 响应 data 为提交瞬间持久化进度快照，不代表执行结果，需轮询 progress/results 接口获取后续状态 |
