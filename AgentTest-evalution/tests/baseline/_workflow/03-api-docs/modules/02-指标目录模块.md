# 指标目录模块 API 文档

> Controller: `IndicatorController`、`IndicatorCatalogVersionController` | Base URL: `http://localhost:8080` | Auth: 无认证（auth_type: none）

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式；本模块全为 GET 查询，无请求体 |
| X-Trace-Id | `{traceId}` | 可选，链路追踪 ID（TraceIdFilter 透传并回写响应头）；缺失时服务端生成 32 位十六进制 UUID |

> 响应统一包装 [ApiResponse](../entities/ApiResponse.md)（code 成功固定 `"200"`，message 固定 `"success"`）；分页数据为 [PageResult](../entities/PageResult.md)（items/page/pageSize/total，pageSize 上限 100）。

---

### 1 查询指标维度列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/api/indicator-dimensions` |
| **接口说明** | 查询指定目录版本（缺省为唯一默认版本）下的指标维度列表，按 sortOrder、id 升序 |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **标签** | indicators |

---

#### 请求

**请求头**: [公开]

**查询参数表**:

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `catalogVersion` | String | 否 | eq | 目录版本编码；缺省时使用唯一默认版本（`is_default=TRUE` 且 `status<>'RETIRED'`），无默认版本返回 409 | `"V1"` |

**请求体**: 无（GET 查询接口，无请求体）

---

#### 响应

##### 成功响应 — HTTP 200

响应体为 [ApiResponse](../entities/ApiResponse.md)，`data` 为 [IndicatorDimension](../entities/IndicatorDimension.md) 数组（SQL 按 `sort_order, id` 排序）：

```json
{
  "code": "200",
  "message": "success",
  "data": [
    {
      "id": 1,
      "dimensionCode": "SECURITY",
      "name": "安全性",
      "defaultWeight": 0.33333333,
      "sortOrder": 1,
      "enabled": true
    }
  ],
  "traceId": "3f2a9c1e0d4b5a7f8e9d0c1b2a3f4e5d"
}
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 404 | COMMON_404_RESOURCE | 指定的 catalogVersion 不存在 | `"Resource not found"` |
| 409 | COMMON_409_CONFLICT | 未传 catalogVersion 且系统中无默认版本；或指定版本状态为 RETIRED | `"Resource conflict"` |
| 500 | COMMON_500_INTERNAL | 未捕获异常 | `"Internal server error"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 版本解析 | `catalogVersion` 缺省 → 查默认版本（`is_default=TRUE` 且未退役）；无默认版本抛 409 |
| 版本解析 | `catalogVersion` 指定 → 按 `version_code` 精确匹配；不存在抛 404；状态为 RETIRED 抛 409 |
| 查询范围 | 仅返回指定 `catalog_version` 下的维度（`WHERE catalog_version=#{catalogVersion}`） |
| 排序 | `ORDER BY sort_order, id` |

| **接口路径** | `/api/indicator-categories` |
| **接口说明** | 查询指定目录版本（缺省为唯一默认版本）下的指标分类列表，支持按维度编码过滤 |
| **认证方式** | 无需认证 |

#### 请求

```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 404 | COMMON_404_RESOURCE | 指定的 catalogVersion 不存在 | `"Resource not found"` |
| 409 | COMMON_409_CONFLICT | 未传 catalogVersion 且系统中无默认版本；或指定版本状态为 RETIRED | `"Resource conflict"` |
| 500 | COMMON_500_INTERNAL | 未捕获异常 | `"Internal server error"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 版本解析 | 同接口 1：缺省用默认版本，无默认版本抛 409；指定版本不存在抛 404；RETIRED 抛 409 |
| 维度过滤 | `dimensionCode` 缺省/空串时不加过滤；非空时按维度编码精确匹配 |
| 表关联 | 分类表 `indicator_category` JOIN 维度表 `indicator_dimension`，维度 `catalog_version` 必须等于目标版本 |
| 排序 | `ORDER BY c.sort_order, c.id` |

### 3 分页查询指标列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/api/indicators` |
| **接口说明** | 分页查询指定目录版本（缺省为唯一默认版本）下的指标，支持维度/分类/方向/采集方式/指标集/启用状态过滤 |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **标签** | indicators |

---

#### 请求

**请求头**: [公开]

**查询参数表**:

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `page` | long | 否 | — | 页码，从 1 开始，默认 `1`；<1 或非数字返回 400 | `1` |
| `pageSize` | long | 否 | — | 每页条数，默认 `20`，范围 1~100；越界或非数字返回 400 | `20` |
| `dimensionCode` | String | 否 | eq | 维度编码精确过滤（`d.dimension_code = #{query.dimensionCode}`） | `"SECURITY"` |
| `categoryCode` | String | 否 | eq | 分类编码精确过滤（`c.category_code = #{query.categoryCode}`） | `"SEC_PRIVACY"` |
| `direction` | String | 否 | eq | 指标方向枚举名精确匹配，可选：`HIGHER_BETTER`/`LOWER_BETTER`/`SCORE_VALUE`/`RANGE_BETTER`；非法值返回 400 | `"LOWER_BETTER"` |
| `collectionMethod` | String | 否 | eq | 证据采集方式枚举名精确匹配，可选：`AUTO_API`/`CONFIG_AUDIT`/`TOOL_TRACE`/`LLM_JUDGE`/`MANUAL_EXPERT`/`HISTORY_COMPARE`/`MONITORING`/`LOAD_TEST`；非法值返回 400 | `"LLM_JUDGE"` |
| `indicatorSet` | String | 否 | eq | 指标集，默认 `CORE`（空串时按 CORE 处理） | `"CORE"` |
| `enabled` | String | 否 | eq | 启用状态精确过滤，可选 `true`/`false`（大小写不敏感）；其他值返回 400 | `"true"` |
| `catalogVersion` | String | 否 | eq | 目录版本编码（`d.catalog_version` 精确匹配）；缺省时使用唯一默认版本，无默认版本返回 409 | `"V1"` |

**请求体**: 无（GET 查询接口，无请求体）

---

        "formulaDescription": "泄露样本数 / 总样本数",
        "unit": "%",
        "metricDirection": "LOWER_BETTER",
        "calculatorType": "NEGATIVE_EVENT_RATE",
        "bestValue": 0,
        "worstValue": 1,
        "entryThreshold": 0.3,
        "runningThreshold": 0.5,
        "thresholdExpression": null,

        "required": true,

  },
  "traceId": "3f2a9c1e0d4b5a7f8e9d0c1b2a3f4e5d"

```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 400 | COMMON_400_VALIDATION | page<1 / pageSize 不在 1~100 / page 或 pageSize 非数字 / direction 或 collectionMethod 非法枚举 / enabled 非 true、false | `"Validation failed"` |
| 404 | COMMON_404_RESOURCE | 指定的 catalogVersion 不存在 | `"Resource not found"` |
| 409 | COMMON_409_CONFLICT | 未传 catalogVersion 且系统中无默认版本；或指定版本状态为 RETIRED | `"Resource conflict"` |
| 500 | COMMON_500_INTERNAL | 未捕获异常 | `"Internal server error"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 版本解析 | 同接口 1：缺省用默认版本，无默认版本抛 409；指定版本不存在抛 404；RETIRED 抛 409 |
| 指标集默认值 | `indicatorSet` 缺省为 `CORE`；传入空串同样按 `CORE` 处理（`withDefaultIndicatorSet`） |
| 参数校验 | 所有筛选/分页参数在 Controller 手工解析：`direction`/`collectionMethod` 按枚举名精确匹配，`enabled` 大小写不敏感（`"TRUE"` 也接受），非法值一律抛 COMMON_400_VALIDATION |
| 分页 | MyBatis-Plus 物理分页，`pageSize` 上限 100（`MAX_PAGE_SIZE` 常量） |
| 查询范围 | `indicator_definition` JOIN 维度表与分类表，维度 `catalog_version` 必须等于目标版本（`d.catalog_version = #{query.catalogVersion}`） |
| ISO 映射 | 每个指标附带 `isoMappings` 列表（`indicator_iso_mapping` 按 `indicator_id IN` 批量查询后分组） |
| 排序 | `ORDER BY i.sort_order, i.id` |

| **权限要求** | 无 |
| **标签** | indicator-catalog-versions |

**请求头**: [公开]

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 500 | COMMON_500_INTERNAL | 未捕获异常（如 risk_weights_json 解析失败） | `"Internal server error"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 无参数 | 接口无任何查询参数，不做校验 |
| 返回范围 | SQL 无 status 过滤（`SELECT ... FROM indicator_catalog_version`），返回全部版本（含 DRAFT/RETIRED 状态），并非仅已发布版本 |
| 排序 | `ORDER BY created_at, version_code` |
| 风险权重 | `riskWeights` 从 `risk_weights_json` 反序列化，权重统一 `setScale(8, HALF_UP)`；解析失败抛 500 |
