## 一、系统概述

智能体评测平台是一个 AI Agent 评测管理系统，前端为 Vue 3 单页应用（5 个业务视图），后端为 Spring Boot（42 个 REST API，`ApiResponse` 统一包装）。核心业务链路：

**Agent 配置 → 指标配置 → 测试用例 → 评测方案 → 创建任务 → 执行评测 → 查看结果**

## 二、业务模块清单

### 模块 1：评测项目（Agent 配置）— 页面 /projects（别名 /agents）

对应后端：/api/agents（5 个接口）

- 1.1 评测项目列表：分页展示 Agent 配置，支持按 code/名称/风险等级/适配器类型/启用状态过滤
- 1.2 创建评测项目：填写 code、名称、风险等级（A/B/C/D）、适配器类型（MINI_ZHEXIAOZHI / GENERIC_HTTP_JSON）、endpoint、超时时间等，创建成功进入列表
- 1.3 查看/编辑评测项目：从列表进入详情，可修改配置并保存
- 1.4 删除评测项目：列表删除（禁用/删除），删除后列表不再展示

### 模块 2：指标配置 — 页面 /indicators

对应后端：/api/indicator-dimensions、/api/indicator-categories、/api/indicators、/api/indicator-catalog-versions（5 个接口）

- 2.1 指标维度浏览：展示指标维度列表（SAFETY_COMPLIANCE/CAPABILITY 等）及默认权重
- 2.2 指标分类浏览：按维度查看指标分类
- 2.3 指标列表：分页展示指标，支持维度/分类/方向/采集方式/指标集/启用状态/目录版本过滤
- 2.4 指标详情：查看单个指标完整信息
- 2.5 目录版本：展示已发布的指标目录版本列表

### 模块 3：测试用例管理 — 评测执行页内（页面 /execution）

对应后端：/api/test-cases（8 个接口，含导入/模板）

- 3.1 测试用例列表：分页展示，支持 indicatorId/维度/分类/类型/启用状态过滤
- 3.2 创建测试用例：填写 code、名称、关联指标、用例类型（SINGLE_TURN/MULTI_TURN/TOOL_CALL/MANUAL_AUDIT）、权重、及格分、版本、组合模式、判定规则（至少 1 条）
- 3.3 编辑/删除测试用例：列表编辑保存、软删除
- 3.4 批量导入：JSON 批量导入、Excel 导入、下载导入模板

### 模块 4：评测方案管理 — 评测执行页内（页面 /execution）

对应后端：/api/evaluation-schemes（10 个接口）

- 4.1 评测方案列表：分页展示，支持 code/名称/状态/模式/类型/风险等级过滤
- 4.2 创建评测方案草稿：填写 code、名称、版本（点分版本号）、评测模式（COMPREHENSIVE/SPECIAL）、风险等级（A/B/C/D）、指标权重等
- 4.3 校验方案：对草稿执行校验，展示校验结果
- 4.4 发布方案：草稿 → 已发布；已发布方案可被任务引用
- 4.5 克隆方案：由已发布方案克隆为草稿
- 4.6 归档/删除方案：未引用草稿物理删除；被引用的已发布方案删除时转归档

### 模块 5：评测执行 — 页面 /execution/:taskId?

对应后端：/api/evaluation-tasks（14 个接口）

- 5.1 创建评测任务：选择 Agent + 已发布方案，创建任务（状态 CREATED，不立即执行）
- 5.2 启动评测：任务点击运行，进入执行中，查看进度（progress）
- 5.3 任务列表/详情：分页查看任务及状态，查看单个任务详情
- 5.4 执行结果：任务完成后查看指标结果、用例判定结果、Agent 调用记录
- 5.5 评测报告：查看任务评测报告（未就绪时提示）
- 5.6 进度与状态流转：CREATED → RUNNING → COMPLETED（或失败），状态冲突有明确提示

### 模块 6：结果看板 — 页面 /results/:taskId?

对应后端：/api/evaluation-tasks/{id}/results 系列（结果/指标/用例/调用/报告查询）

- 6.1 结果总览：按任务查看评测结果汇总与维度得分
- 6.2 明细下钻：指标结果、用例判定结果、Agent 调用记录（脱敏）
- 6.3 报告查看：查看持久化评测报告；未就绪时页面有明确提示

### 模块 7：总览 — 页面 /overview

- 7.1 总览页展示平台核心数据入口：评测项目/指标/执行/结果导航与统计概览
- 7.2 页面各导航可正确跳转到对应业务页面

## 三、通用规则（场景设计约束）

- 前端无登录鉴权，UI 测试不涉及登录/登出
- 创建类操作优先使用「时间戳后缀」唯一标识避免重复冲突（如 AGT_UI_20260820_1001）
- 涉及状态机（方案发布/任务运行）的场景遵循后端状态机顺序
- 场景需与后端接口测试互补：接口层已覆盖 42 API 全量用例，UI 层聚焦"页面可达性 + 主链路操作 + 关键交互反馈"（每模块 1-2 个核心场景 + 1 个反向场景）
- 断言以页面可见文案/路由跳转/反馈消息为准（后端解析的文案提取见 03 阶段）
