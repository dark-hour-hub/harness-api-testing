## 2. 业务流程（叙述）

### 2.1 总览
进入系统后展示平台核心数据入口与统计概览。用户可通过导航卡片/快捷入口跳转到评测项目、指标配置、评测执行、结果看板四个业务页面，跳转后页面正确加载。

### 2.2 评测项目（智能体配置）
用户进入评测项目页，看到智能体卡片列表，可按编码筛选。点击「新增智能体」打开表单弹窗，填写：编码（必填、唯一）、名称（必填）、分类、风险等级（A/B/C/D）、所属部门、版本、示例分类、适配器类型、HTTP 方法、接口地址、超时时间（毫秒）、报文路径等；点击「保存」成功后弹提示，列表出现新卡片。点击卡片「编辑」可修改配置并保存；点击「删除」弹确认框，确认后删除（无评测任务引用时物理删除；有引用时仅停用），列表不再展示。

### 2.3 指标配置
展示指标维度（含默认权重）、分类、指标列表（支持维度/分类/方向/采集方式/指标集/启用状态/目录版本过滤）与指标详情。目录版本列表展示已发布版本。此模块 UI 侧以浏览为主；测试用例的创建入口在此页（选择指标后「新增用例」）。

### 2.4 测试用例管理
在指标上下文中新增测试用例：表单含用例编码（必填、唯一）、用例名称（必填）、关联指标（当前上下文锁定）、用例类型（SINGLE_TURN/MULTI_TURN/TOOL_CALL/MANUAL_AUDIT）、用例权重、通过分数、版本、组合模式、判定规则（至少 1 条，含规则类型/权重/必选/启用/规则配置）。保存成功提示「测试用例已新增」。列表支持编辑保存（提示「测试用例已更新」）、删除（软删除，提示「测试用例已删除」）、批量导入（JSON/Excel）。

### 2.5 评测方案管理
创建评测方案：填写编码、名称、版本（点分版本号）、评测模式（COMPREHENSIVE/SPECIAL）、风险等级（A/B/C/D）、目录版本、维度权重、所选指标分类与指标、测试用例。可「保存为草稿」（提示「评测方案已保存为草稿」）或「保存并发布」（提示「评测方案已保存并发布」）。草稿可校验（展示校验结果）、编辑；已发布方案可克隆为草稿、可被任务引用。删除：未引用草稿物理删除；被引用已发布方案删除时转归档（提示对应删除/归档结果）。

### 2.6 评测执行
选择智能体（评测项目）与已发布评测方案，创建评测任务（初始状态 CREATED，不立即执行）。点击「开始执行」启动评测，任务进入 RUNNING 并展示进度；完成后 COMPLETED（或失败），查看指标结果、用例判定结果、Agent 调用记录与评测报告。

### 2.7 结果看板
按任务查看评测结果：汇总与维度得分、指标结果、用例判定结果、Agent 调用记录（脱敏）、持久化评测报告（未就绪时页面有明确提示）。

## 4. 字段明细（复杂场景补充）

### 4.1 智能体配置表
- 编码：新增必填，来自表单「智能体编码」，全局唯一（uk）
- 名称：新增必填，来自表单「请输入智能体名称」
- 分类：必填，如 TEST
- 风险等级：枚举{A,B,C,D}，下拉「风险等级」
- 适配器类型：枚举{MINI_ZHEXIAOZHI, GENERIC_HTTP_JSON}，下拉「适配器类型」
- HTTP 方法：枚举{GET,POST,PUT,DELETE}，下拉「HTTP 方法」
- 接口地址：必填，URL
- 超时时间：必填，毫秒（合法范围 100-120000）
- 启用状态：新增默认 1；删除（有引用）置 0

### 4.2 测试用例表
- 编码：新增必填，唯一
- 名称：新增必填
- 关联指标：新增必填，由当前指标上下文锁定（不可迁移）
- 用例类型：枚举{SINGLE_TURN, MULTI_TURN, TOOL_CALL, MANUAL_AUDIT}
- 权重：必填，数值
- 通过分数：必填，0-100
- 版本：必填
- 判定规则：至少 1 条；每条含类型/权重/必选/启用/规则配置
- 启用状态：新增默认 1；删除（软删除）标记 SOFT_DELETED

### 4.3 评测方案表
- 编码：新增必填，唯一（编码+版本联合唯一）
- 版本：点分版本号
- 评测模式：枚举{COMPREHENSIVE, SPECIAL}
- 风险等级：枚举{A,B,C,D}
- 目录版本：必选（V1/V2），决定维度/分类/指标范围
- 维度权重：各维度权重和=1（同分类内指标 weightOverride 和=1）
- 状态：{DRAFT 草稿, PUBLISHED 已发布, ARCHIVED 已归档}

### 4.4 评测任务表
- 关联智能体：必选（启用的智能体）
- 关联方案：必选（已发布方案，ARCHIVED 不可作来源）
- 状态机：CREATED → RUNNING → COMPLETED / FAILED

## 5. 数据约束（可选）

- **唯一约束**：智能体编码唯一（重复新增被拒）；测试用例编码唯一；方案（编码+版本）联合唯一——**重复执行创建类用例会冲突，场景必须使用动态值**（如 `${ts}` 时间戳后缀）
- **种子依赖**：预置种子智能体（编码如 CHAT、BANK_AGENT、AGT_SEED_*）**不可被 UI 操作删除/停用/修改**；压测基准方案 PERF_SCHEME_BASE（PUBLISHED）可被任务创建引用
- **删除语义**：智能体有任务引用→仅停用（启用状态=0）；方案被引用→转归档（ARCHIVED）；未引用→物理删除
- **状态机顺序**：任务创建必须引用 PUBLISHED 方案；ARCHIVED 方案不可删除/不可作来源；DRAFT 方案不可被任务引用
- **时间字段**：periodStart/End 为本地时间（不带时区偏移）
- **导入数据**：批量导入用例必须含 referenceAnswer；CONTAINS 规则必须配置 keywords
