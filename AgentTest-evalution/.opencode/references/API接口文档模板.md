## 响应包装说明

所有接口响应均经过统一的包装类处理，以下为框架级定义。

### R\<T\> — 非分页响应

| 字段路径 | 类型 | 可空 | 说明 | 示例值 |
|----------|------|:---:|------|--------|
| code | Integer | 否 | 业务状态码 | `200` |
| {msg_field} | String | 否 | 业务消息 | `"操作成功"` |
| data | T | 是 | 业务数据（泛型），无数据时为 `null` | `{...}` |

> `{msg_field}` 必须从 R 类源码确认实际字段名（如 `msg`、`message`），不可假设。

### TableDataInfo\<T\> — 分页响应

| 字段路径 | 类型 | 可空 | 说明 | 示例值 |
|----------|------|:---:|------|--------|
| code | Integer | 否 | 固定值 | `200` |
| {msg_field} | String | 否 | 固定值 | `"查询成功"` |
| rows | List\<T\> | 否 | 当前页数据列表 | `[{...}]` |
| total | Long | 否 | 总记录数 | `100` |
