## 项目简介

一句话描述系统定位与主要功能。

## 角色与账号

| 角色 | 账号 | 权限范围 |
|------|------|----------|
| 管理员 | admin / admin123 | 图书管理、用户管理、借阅管理等全部权限 |
| 普通用户 | user / 123456 | 浏览图书、借阅/续借/归还、收藏、评论 |

## 业务模块清单

| 模块 | 业务说明 | 核心流程 | 优先级 |
|------|----------|----------|--------|
| 登录 | 角色登录系统 | 打开首页 → 输入账号密码 → 登录进入工作台 | P0 |
| 图书管理 | 管理员新增/编辑/删除图书，用户浏览检索 | 进入图书管理 → 查询 → 新增/借阅 | P0 |

## 关键业务流程

### 1. 登录

1. 打开系统首页
2. 输入账号密码，点击登录
3. 登录成功后进入工作台

### 2. 示例：图书借阅

1. 登录普通用户账号
2. 进入「图书管理」
3. 按书名搜索目标图书
4. 点击「借阅」并确认
5. 看到「借阅成功」提示
