#### 业务规则

| 序号 | 规则描述 |
|:----:|----------|
| 1 | 新增时校验 `AddGroup`，`parentId` 和 `categoryName` 必填 |
| 2 | 分类名称在同一父级下必须唯一（`categoryName` + `parentId` 组合唯一） |
| 3 | 父级分类必须存在，否则抛出 `"父级流程分类不存在!"` |
| 4 | 自动计算 `ancestors`：`父级ancestors + "," + parentId` |
| 5 | 受 `@RepeatSubmit` 防重保护，防止重复提交 |

| 200 | 500 | 重复提交 | `"不允许重复提交，请稍候再试"` |

| 序号 | 规则描述 |
|:----:|----------|
| 1 | `active=true` 时调用 `defService.active(id)` 激活流程 |
