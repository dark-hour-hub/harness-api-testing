# 兽医管理 API 文档

> Controller: `VetController` | Base URL: `http://localhost:8080` | Auth: 无认证（所有接口无需登录）

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` 或 `application/x-www-form-urlencoded` | 请求体格式 |

> 无认证请求头，无权限控制。

---

### 1 获取兽医列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/vets` |
| **接口说明** | 获取所有兽医及其专业领域列表，以 JSON 格式返回 |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **标签** | 列表查询 |
| **特殊属性** | `@ResponseBody`（JSON 响应，项目中唯一的 JSON API） |

---

#### 请求

**请求头**: [公开]

无路径参数。

无查询参数。

无请求体。

---

#### 响应

##### 成功响应 — HTTP 200

返回 [Vets](../entities/Vets.md) 实体，内嵌 [Vet](../entities/Vet.md) 数组。

```json
{
  "vetList": [
    {
      "id": 1,
      "firstName": "James",
      "lastName": "Carter",
      "specialties": [],
      "nrOfSpecialties": 0
    },
    {
      "id": 2,
      "firstName": "Helen",
      "lastName": "Leary",
      "specialties": [
        {
          "id": 1,
          "name": "radiology"
        }
      ],
      "nrOfSpecialties": 1
    }
  ]
}
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 500 | — | 服务器内部错误（数据库连接异常、内存溢出等） | 服务端异常 |

> GET 查询请求无业务校验错误。数据库无数据时返回空列表 `{"vetList": []}`，不视为错误。
