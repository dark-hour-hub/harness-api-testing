# 代码生成 API 文档

> Controller: `GenController` | Base URL: `http://localhost:8080` | Auth: Sa-Token JWT `Authorization: Bearer {token}` + `clientid: e5cd7e4891bf95d1d19206ce24a7b32e`

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式 |
| Authorization | `Bearer {token}` | Sa-Token JWT 令牌，登录后获取 |
| clientid | `e5cd7e4891bf95d1d19206ce24a7b32e` | 客户端 ID，与 Token 绑定 |

### 1 查询代码生成列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/tool/gen/list` |
| **接口说明** | 分页查询已导入的代码生成配置列表 |
| **认证方式** | 需要认证 |
| **权限要求** | `tool:gen:list` |
| **标签** | 代码生成 |

---

#### 请求

**请求头**: [认证]

**查询参数**:

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `pageNum` | Integer | 否 | — | 当前页码，默认 1 | `1` |
| `pageSize` | Integer | 否 | — | 每页条数，默认 Integer.MAX_VALUE | `10` |
| `orderByColumn` | String | 否 | — | 排序列名（驼峰，会自动转下划线） | `"createTime"` |
| `isAsc` | String | 否 | — | 升序/降序 (asc/desc/ascending/descending) | `"desc"` |
| `dataName` | String | 否 | eq | 数据源名称，精确匹配 | `"master"` |
| `tableName` | String | 否 | like | 表名称，模糊匹配（忽略大小写） | `"sys"` |
| `tableComment` | String | 否 | like | 表描述，模糊匹配（忽略大小写） | `"用户"` |

**区间查询参数** (通过 `params` 对象传递):

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `params[beginTime]` | String | 否 | between | 创建时间起始 | `"2026-01-01 00:00:00"` |
| `params[endTime]` | String | 否 | between | 创建时间结束 | `"2026-12-31 23:59:59"` |

> 注：`beginTime` 和 `endTime` 必须同时提供才会生效，区间匹配 `create_time` 字段。

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 表名转换 | `tables` 参数由逗号分隔的字符串自动拆分为数组，每个表名分别处理 |
| 数据源路由 | 根据 `dataName` 切换数据源查询数据库元数据 |
| 表初始化 | 调用 `GenUtils.initTable()` 自动填充表相关默认配置（如类名、包路径等） |
| 字段导入 | 每个表导入时自动读取数据库列的元数据，并调用 `GenUtils.initColumnField()` 初始化字段配置 |
| 事务性 | 使用 `@DSTransactional` 保证多数据源下的事务一致性 |

## 附录

### 错误响应机制说明

本模块错误响应遵循以下三层处理链：

| 层级 | 触发点 | 异常类型 | 全局处理器 | HTTP 状态 | code | msg 来源 |
|------|--------|----------|-----------|:---------:|:----:|----------|
| 1. DTO 校验 | GenTable 字段 `@NotBlank` 注解 | `MethodArgumentNotValidException` | `handleMethodArgumentNotValidException` | 200 | 500 | 注解 `message` 属性硬编码字符串 |
| 2. Service 校验 | `validateEdit()` 方法中 `throw new ServiceException(msg)` | `ServiceException` | `handleServiceException` | 200 | 500 | 硬编码字符串（code=null 时默认 500） |
| 3. Sa-Token 拦截 | `@SaCheckPermission` / Token 校验 | Sa-Token 框架异常 | Sa-Token Filter | 401/403 | 401/403 | 框架固定消息 |

### 代码生成模板说明

代码生成基于 Apache Velocity 模板引擎，支持的模板分类：

| tplCategory | 说明 | 生成内容 |
|-------------|------|----------|
| `crud` | 单表操作 | Controller, Service, ServiceImpl, Mapper, Mapper.xml, Entity, 前端 Vue 页面等 |
| `tree` | 树表操作 | 除 CRUD 模板外，额外生成树形结构相关代码 |
| `sub` | 主子表操作 | 生成主子表关联代码，包含子表模块 |

### 权限标识汇总

| 权限标识 | 关联接口 |
|----------|----------|
| `tool:gen:list` | 查询代码生成列表、查询数据库列表、查询数据表字段列表、查询数据源名称列表 |
| `tool:gen:query` | 查询代码生成业务详情 |
| `tool:gen:import` | 导入表结构 |
| `tool:gen:edit` | 修改保存代码生成业务、同步数据库 |

| `tool:gen:preview` | 预览代码 |
| `tool:gen:code` | 生成代码（下载方式）、批量生成代码 |
