|------|-----|

| **接口路径** | `/system/tenant/list` |

#### 请求

**请求头**: [认证]

**查询参数**:

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `pageNum` | Integer | 否 | — | 当前页码，默认 1 | `1` |

### 4 新增租户

| 属性 | 值 |
|------|-----|
| **请求方式** | `POST` |
| **接口路径** | `/system/tenant` |
| **接口说明** | 新增租户，同时创建默认角色、部门、管理员用户及初始数据（字典、参数配置），请求体加密 |
| **认证方式** | 需要认证 |
| **权限要求** | `system:tenant:add` + 超管角色 |
| **标签** | 系统管理-租户管理 |
| **加密** | `@ApiEncrypt` — 请求体需要加密传输 |
| **分布式锁** | `@Lock4j` — 分布式锁防并发 |
| **防重提交** | `@RepeatSubmit` — 不允许重复提交 |

---

#### 请求

**请求头**: [认证] + 请求体加密

请求体: [SysTenantBo](../entities/SysTenantBo.md)

> 请求体经过 `@ApiEncrypt` 加密处理，客户端需对请求体进行加密后传输。校验分组 `AddGroup`：`contactUserName`、`contactPhone`、`companyName`、`username`、`password`、`packageId` 为必填。

---

#### 响应

##### 成功响应 — HTTP 200

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": null
}
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 200 | 200 | 操作成功 | `"操作成功"` |

| 403 | 403 | 权限不足或非超管角色 | `"没有访问权限，请联系管理员授权"` |
| 200 | 500 | DTO 校验失败（必填字段缺失） | 对应字段的校验消息（如"* 必须填写"） |
| 200 | 500 | 企业名称已存在 | `"新增租户'{companyName}'失败，企业名称已存在"` |
| 200 | 500 | 数据库插入失败 | `"创建租户失败"` |
| 200 | 500 | 操作失败（row <= 0） | `"操作失败"` |
| 200 | 500 | 重复提交 | `"不允许重复提交，请稍候再试"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 企业名称唯一性 | 新增前校验企业名称是否已存在，重复则返回失败 |
| 租户编号自动生成 | 系统自动生成租户编号（格式如 T0001） |
| 级联创建 | 新增租户同时创建默认角色（关联套餐菜单）、默认部门（公司名称）、管理员用户、复制默认字典数据、复制默认参数配置 |
| 加密传输 | 请求体需通过 `@ApiEncrypt` 加密 |
| 防并发 | `@Lock4j` 分布式锁防止并发创建 |
| 防重复 | `@RepeatSubmit` 防止短时间内重复提交 |
