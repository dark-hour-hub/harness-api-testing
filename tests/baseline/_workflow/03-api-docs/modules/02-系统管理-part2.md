# 角色管理 API 文档

> Controller: `SysRoleController` | Base URL: `http://localhost:8080` | Auth: Sa-Token JWT `Authorization: Bearer {token}` + `clientid: e5cd7e4891bf95d1d19206ce24a7b32e`

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式；文件上传使用 `multipart/form-data` |
| Authorization | `Bearer {token}` | Sa-Token JWT 令牌，登录后获取 |
| clientid | `e5cd7e4891bf95d1d19206ce24a7b32e` | 客户端 ID，与 Token 绑定 |

---

### 1 获取角色信息列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/system/role/list` |
| **接口说明** | 分页查询角色信息列表，支持按角色名称、权限字符串、状态、创建时间范围筛选 |
| **认证方式** | 需要认证 |
| **权限要求** | `system:role:list` |
| **标签** | 角色管理-查询 |

---

#### 请求

**请求头**: [认证]

**查询参数**:

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `pageNum` | Integer | 否 | — | 当前页码，默认 1 | `1` |
| `pageSize` | Integer | 否 | — | 每页条数，默认 10 | `10` |
| `orderByColumn` | String | 否 | — | 排序列名 | `"createTime"` |
| `isAsc` | String | 否 | — | 升序/降序 (asc/desc) | `"desc"` |
| `roleId` | Long | 否 | eq | 角色ID，精确匹配 | `1` |
| `roleName` | String | 否 | like | 角色名称，模糊匹配 | `"管理员"` |
| `status` | String | 否 | eq | 角色状态（`0` 正常、`1` 停用），精确匹配 | `"0"` |
| `roleKey` | String | 否 | like | 角色权限字符串，模糊匹配 | `"admin"` |
| `params[beginTime]` | String | 否 | between | 创建时间起始，与 endTime 配合使用 | `"2026-01-01"` |
| `params[endTime]` | String | 否 | between | 创建时间截止，与 beginTime 配合使用 | `"2026-12-31"` |

默认排序：按 `roleSort` 升序 → `createTime` 升序

---

#### 响应

##### 成功响应 — HTTP 200

**[SysRoleVo](../entities/SysRoleVo.md)** 分页列表，外层包裹 `TableDataInfo`：

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    "rows": [
      {
        "roleId": 1,
        "roleName": "超级管理员",
        "roleKey": "superadmin",
        "roleSort": 1,
        "dataScope": "1",
        "menuCheckStrictly": true,
        "deptCheckStrictly": true,
        "status": "0",
        "remark": "超级管理员角色",
        "createTime": "2025-01-01 10:00:00",
        "flag": false
      }
    ],
    "total": 1
  }
}
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 200 | 500 | 用户没有对应部门/创建人的数据权限 | `"没有权限访问部分角色数据！"` |

##### 成功响应 — HTTP 200

```json
{
  "code": 200,
  "msg": "操作成功",
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 200 | 200 | 操作成功 | `"操作成功"` |
| 401 | 401 | Token 缺失或失效 | `"认证失败，无法访问系统资源"` |
| 403 | 403 | 权限不足 | `"没有访问权限，请联系管理员授权"` |
| 200 | 500 | roleName 为空（DTO 校验） | `"角色名称不能为空"` |
| 200 | 500 | roleName 长度超过 30 字符（DTO 校验） | `"角色名称长度不能超过30个字符"` |

| 200 | 500 | roleSort 为 null（DTO 校验） | `"显示顺序不能为空"` |
| 200 | 500 | 使用系统内置管理员角色标识符（如 `superadmin`、`tenantadmin`） | `"不允许使用系统内置管理员角色标识符!"` |
| 200 | 500 | 角色名称已存在 | `"新增角色'{roleName}'失败，角色名称已存在"` |
| 200 | 500 | 角色权限字符串已存在 | `"新增角色'{roleName}'失败，角色权限已存在"` |

---

#### 业务规则

| 规则项 | 规则内容 |
|--------|---------|
| **名称唯一性** | 角色名称在同一系统中不可重复 |
| **权限标识符唯一性** | 角色权限字符串（roleKey）在同一系统中不可重复 |
| **内置角色保护** | 新增时不允许使用系统内置的管理员角色标识符 `superadmin` 和 `tenantadmin` |
| **关联插入** | 新增角色后自动插入角色-菜单关联关系（`sys_role_menu`） |

---

#### 业务规则

| 规则项 | 规则内容 |
|--------|---------|
| **角色保护** | 不允许直接修改超级管理员角色的信息 |
| **标识符保护** | 不允许将内置管理员角色的标识符（`superadmin`、`tenantadmin`）修改为其他值，也不允许将其他角色的标识符修改为内置标识符 |
| **禁用限制** | 已分配用户的角色不允许禁用 |
| **菜单关联** | 修改角色时先删除旧的菜单关联，再插入新的菜单关联 |
| **在线用户清除** | 修改成功后，清除所有关联该角色的在线用户的登录态 |

---

#### 业务规则

| 规则项 | 规则内容 |
|--------|---------|
| **数据权限校验** | 批量删除前校验所有传入的角色ID是否都在当前用户的数据权限范围内 |
| **超级管理员保护** | 不允许删除超级管理员角色 |
| **分配校验** | 已分配给用户的角色不允许删除（逐条检查） |
| **关联删除** | 删除角色时同时删除 `sys_role_menu`（角色-菜单关联）和 `sys_role_dept`（角色-部门关联）的记录 |
| **缓存清除** | 删除成功后清除角色自定义缓存 |
