# 监控管理 API 文档

> Controller: `SysLogininforController`, `SysOperlogController`, `SysUserOnlineController`, `CacheController` | Base URL: `http://localhost:8080` | Auth: Sa-Token JWT `Authorization: Bearer {token}` + `clientid: e5cd7e4891bf95d1d19206ce24a7b32e`

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式；导出接口使用普通表单或 JSON |
| Authorization | `Bearer {token}` | Sa-Token JWT 令牌，登录后获取 |
| clientid | `e5cd7e4891bf95d1d19206ce24a7b32e` | 客户端 ID，与 Token 绑定 |

---

### 1 获取系统访问记录列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/monitor/logininfor/list` |
| **接口说明** | 分页查询系统访问记录（登录日志）列表，支持按 IP、状态、用户名、时间范围筛选 |
| **认证方式** | 需要认证 |
| **权限要求** | `monitor:logininfor:list` |
| **标签** | 查询 |

---

#### 请求

**请求头**: [认证]

**查询参数**:

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `pageNum` | Integer | 否 | — | 当前页码，默认 1 | `1` |
| `pageSize` | Integer | 否 | — | 每页条数，默认 Integer.MAX_VALUE | `10` |
| `orderByColumn` | String | 否 | — | 排序列名 | `"infoId"` |
| `isAsc` | String | 否 | — | 升序/降序 (asc/desc) | `"desc"` |
| `ipaddr` | String | 否 | like | 登录 IP 地址，模糊匹配 | `"192.168"` |
| `status` | String | 否 | eq | 登录状态：0=成功，1=失败 | `"0"` |
| `userName` | String | 否 | like | 用户账号，模糊匹配 | `"admin"` |
| `params[beginTime]` | String | 否 | between | 访问开始时间（配合 endTime 区间查询 loginTime） | `"2026-01-01"` |
| `params[endTime]` | String | 否 | between | 访问结束时间（配合 beginTime 区间查询 loginTime） | `"2026-12-31"` |

> 默认排序：`infoId DESC`（未指定 orderByColumn 时）。Bo 中其他字段（tenantId、clientKey、deviceType、loginLocation、browser、os、msg）虽可从 query string 绑定，但 buildQueryWrapper 未用于过滤。

|--------|------|
| 幂等性 | 清理后再次调用仍返回成功（空表 truncate 无害） |

| 不可恢复 | 清理操作直接 truncate 表，数据不可恢复 |

##### 错误响应

|:----:|:----:|----------|-----|

| 规则项 | 说明 |
|--------|------|

| 防重机制 | `@RepeatSubmit`（默认配置）拦截短时间内重复的解锁请求 |
| 缓存 Key | `CacheConstants.PWD_ERR_CNT_KEY + userName`，存储用户的密码错误次数 |

#### 业务规则

| 异常处理 | 获取连接或执行命令时的异常通过全局异常处理器 `Exception.class` 捕获返回 500 |
