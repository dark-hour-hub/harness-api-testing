# 客户管理 API 文档

> Controller: `OwnerController` / `PetController` / `VisitController` | Base URL: `http://localhost:8080` | Auth: 无认证（所有接口无需登录）

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/x-www-form-urlencoded` | POST 表单提交格式（GET 请求无需此头） |

---

### 1 查询客户列表（按姓氏分页搜索）

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/owners` |
| **接口说明** | 按姓氏搜索客户，支持分页展示；未指定姓氏时展示所有客户（分页）；若搜索无结果则返回查找表单并提示"has not been found" |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **Controller** | OwnerController |
| **标签** | 列表查询、分页查询 |

---

#### 请求

**请求头**: 无特殊要求

##### 查询参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|:---:|------|------|
| `lastName` | String | 否 | 客户姓氏，用于模糊搜索；为空时返回所有客户 | `"Franklin"` |
| `page` | int | 否 | 当前页码，默认 1 | `1` |

---

#### 响应

##### 成功响应 — HTTP 200

- **有搜索结果**: 返回 Thymeleaf 视图 `owners/ownersList`，视图含分页对象（`Page<Owner>`），每页约 5 条记录，包含 Owner 及其 pets。
- **无搜索结果**: 返回 Thymeleaf 视图 `owners/findOwners`，视图含一条提示消息：`"has not been found"`。

##### 错误响应

| HTTP | 触发条件 | 表现 |
|:----:|----------|------|
| 200 | 未指定 `lastName` 且数据库无任何 Owner | 返回 `owners/ownersList`，列表为空 |
| 500 | 数据库连接异常或服务内部错误 | 返回 error 视图 |

### 4 新增客户

| 属性 | 值 |
|------|-----|
| **请求方式** | `POST` |
| **接口路径** | `/owners/new` |
| **接口说明** | 提交客户信息，创建新客户记录 |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **Controller** | OwnerController |
| **标签** | 新增 |

---

#### 请求

**请求头**: `Content-Type: application/x-www-form-urlencoded`

##### 请求体 — 表单绑定

[Owner](../entities/Owner.md)（表单绑定字段: `firstName`, `lastName`, `address`, `city`, `telephone`）

**校验规则**:
- `firstName`: `@NotBlank`, `@Size(max=30)`
- `lastName`: `@NotBlank`, `@Size(max=30)`
- `address`: `@NotBlank`
- `city`: `@NotBlank`
- `telephone`: `@NotBlank`, `@Pattern(regexp="\\d{10}")`

---

#### 响应

##### 成功响应 — HTTP 302

`redirect:/owners/{id}` — 重定向到新创建的客户详情页。

##### 错误响应

| HTTP | 触发条件 | 表现 |
|:----:|----------|------|
| 302 | `@Valid` 校验失败（字段为空、超长、手机号格式不正确） | 重定向回 `/owners/new` 表单页，flash attribute `error` 含校验错误消息 |
| 500 | 数据库写入失败或服务内部错误 | 返回 error 视图 |
