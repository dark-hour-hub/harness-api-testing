> Controller: `SysMenuController`, `SysDeptController` | Base URL: `http://localhost:8080` | Auth: Sa-Token JWT `Authorization: Bearer {token}` + `clientid: e5cd7e4891bf95d1d19206ce24a7b32e`

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式 |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 仅返回目录和菜单类型 | 过滤掉按钮类型（`F`）的菜单，只返回 `M`（目录）和 `C`（菜单） |
| 超级管理员 | 返回全部菜单路由 |
| 非管理员 | 按用户角色关联的菜单权限过滤，仅返回有权限的路由 |
| 外链处理 | 外链菜单（`isFrame=0`）会生成特殊的路由结构（内嵌 iframe） |
| 路由命名 | 路由 name 按 `首字母大写path + menuId` 规则生成，如 `System1` |

### 2 获取菜单列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/system/menu/list` |
| **接口说明** | 获取菜单列表，支持按菜单名称、可见性、状态、类型等条件筛选 |
| **认证方式** | 需要认证 |
| **权限要求** | `system:menu:list`（且需要 `super_admin` 或 `tenant_admin` 角色） |
| **标签** | 菜单管理, 查询 |

---

#### 请求

**请求头**: [认证]

无路径参数。

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `menuName` | String | 否 | like | 菜单名称，模糊匹配 | `"用户"` |
| `visible` | String | 否 | eq | 显示状态（`0` 显示、`1` 隐藏） | `"0"` |
| `status` | String | 否 | eq | 菜单状态（`0` 正常、`1` 停用） | `"0"` |
| `menuType` | String | 否 | eq | 菜单类型（`M` 目录、`C` 菜单、`F` 按钮） | `"C"` |
| `parentId` | Long | 否 | eq | 父菜单ID | `0` |

无请求体。

---

#### 响应

##### 成功响应 -- HTTP 200

[SysMenuVo](../entities/SysMenuVo.md) 列表，外覆 `R<List<SysMenuVo>>`。菜单按 `parentId`、`orderNum` 升序排列。

```json
{
  "code": 200,
  "msg": "操作成功",
  "data": [
    {
      "menuId": 1,
      "menuName": "系统管理",
      "parentId": 0,
      "orderNum": 1,
      "path": "/system",
      "component": "",
      "isFrame": "1",
      "isCache": "0",
      "menuType": "M",
      "visible": "0",
      "status": "0",
      "perms": "",
      "icon": "system",
      "createTime": "2025-01-01 10:00:00",
      "children": []
    }
  ]
}
```

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 401 | 401 | Token 缺失或失效 | `"认证失败，无法访问系统资源"` |
| 403 | 403 | 角色不满足（非 super_admin 且非 tenant_admin）或权限不足 | `"没有访问权限，请联系管理员授权"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 角色限制 | 仅超级管理员（`super_admin`）或租户管理员（`tenant_admin`）可调用 |
| 非管理员过滤 | 非管理员用户仅返回其角色关联的菜单 |
| 排序 | 按 `parentId` 升序、`orderNum` 升序排列 |
| 结果不含 children | 此接口返回扁平列表，不含树形结构 |

| 200 | 500 | 路由名称或地址已存在 | `"新增菜单'{菜单名}'失败，路由名称或地址已存在"` |
| 200 | 500 | 防重提交拦截 | `"不允许重复提交，请稍候再试"` |

---

#### 业务规则

| 规则 | 说明 |
|------|------|
| 角色限制 | 仅超级管理员（`super_admin`）可操作 |
| 菜单名称唯一性 | 同一父菜单下菜单名称不可重复 |
| 外链校验 | 当 `isFrame=0`（是外链）时，`path` 必须以 `http://` 或 `https://` 开头 |
| 路由唯一性 | 路由名称和路由地址的组合不可与已有菜单重复 |
| 防重提交 | 5 秒内不允许重复提交（基于 `@RepeatSubmit` 默认间隔） |

| 用户关联检查 | 该部门下存在已分配用户时不允许删除 |
| 岗位关联检查 | 该部门下存在岗位时不允许删除 |
| 数据权限 | 非管理员需校验是否具备该部门的数据权限，无权限抛出 `ServiceException` |
| 检查顺序 | 按 默认部门 → 子部门 → 用户 → 岗位 → 数据权限 顺序校验 |

### 17 获取部门选择框列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/system/dept/optionselect` |

| **认证方式** | 需要认证 |
| **权限要求** | `system:dept:query` |
| **标签** | 部门管理, 查询, 下拉 |

无路径参数。

```json
  ]

```

#### 业务规则

| 规则 | 说明 |
|------|------|
