# 系统管理 -- 用户管理 + 个人中心 API 文档

> Controller: `SysUserController`, `SysProfileController` | Base URL: `http://localhost:8080` | Auth: Sa-Token JWT `Authorization: Bearer {token}` + `clientid: e5cd7e4891bf95d1d19206ce24a7b32e`

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/json` | 请求体格式；文件上传使用 `multipart/form-data` |
| Authorization | `Bearer {token}` | Sa-Token JWT 令牌，登录后获取 |
| clientid | `e5cd7e4891bf95d1d19206ce24a7b32e` | 客户端 ID，与 Token 绑定 |

### 1 获取用户列表

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/system/user/list` |
| **接口说明** | 分页查询用户列表，支持多条件筛选（用户名、昵称、手机号、状态、部门、创建时间区间等） |
| **认证方式** | 需要认证 |
| **权限要求** | `system:user:list` |
| **标签** | 用户管理, 查询 |

---

#### 请求

**请求头**: [认证]

**查询参数**:

| 参数名 | 类型 | 必填 | 匹配方式 | 说明 | 示例 |
|--------|------|:---:|:---:|------|------|
| `pageNum` | Integer | 否 | -- | 当前页码，默认 1 | `1` |
| `pageSize` | Integer | 否 | -- | 每页条数，默认 10 | `10` |
| `orderByColumn` | String | 否 | -- | 排序列名 | `"createTime"` |
| `isAsc` | String | 否 | -- | 升序/降序 (asc/desc) | `"desc"` |
| `userId` | number | 否 | eq | 用户ID，精确匹配 | `1` |
| `userName` | string | 否 | like | 用户账号，模糊匹配 | `"admin"` |
| `nickName` | string | 否 | like | 用户昵称，模糊匹配 | `"管理员"` |
| `status` | string | 否 | eq | 账号状态（`0` 正常、`1` 停用） | `"0"` |
| `phonenumber` | string | 否 | like | 手机号码，模糊匹配 | `"138"` |
| `deptId` | number | 否 | in | 部门ID（含子部门，通过 deptTree 查询子孙部门后 IN 查询） | `103` |
| `userIds` | string | 否 | in | 用户ID串（逗号分隔） | `"1,2,3"` |
| `excludeUserIds` | string | 否 | notIn | 排除的用户ID串（逗号分隔） | `"100"` |
| `params[beginTime]` | string | 否 | between | 创建时间起始（配合 params 传入） | `"2026-01-01"` |
| `params[endTime]` | string | 否 | between | 创建时间结束（配合 params 传入） | `"2026-07-14"` |
