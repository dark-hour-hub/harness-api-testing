# 首页 API 文档

> Controller: `WelcomeController` | Base URL: `http://localhost:8080` | Auth: 无认证（所有接口无需登录）

## 请求头

| 头名称 | 值 | 说明 |
|--------|-----|------|
| Content-Type | `application/x-www-form-urlencoded` | 表单提交时使用；GET 请求无需设置 |

---

### 1 欢迎页

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/` |
| **接口说明** | 返回欢迎页（Thymeleaf 视图），展示 Spring PetClinic 首页 HTML 页面 |
| **认证方式** | 无需认证 |
| **权限要求** | 无 |
| **标签** | 正常 |

---

#### 请求

**请求头**: 公开

无路径参数、无查询参数、无请求体。

---

#### 响应

##### 成功响应 — HTTP 200

返回 Thymeleaf 视图 `welcome`，渲染为 HTML 页面。响应 Content-Type 为 `text/html`。

视图名称: `welcome`

##### 错误响应

| HTTP | code | 触发条件 | msg |
|:----:|:----:|----------|-----|
| 500 | — | 服务器内部错误（模板渲染失败、Thymeleaf 配置异常等） | 服务器错误页面 |

---

#### 业务规则

无特殊业务规则。
