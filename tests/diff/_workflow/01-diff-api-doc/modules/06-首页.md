---

#### 响应

##### 成功响应 — HTTP 200

返回纯文本字符串（非 JSON 统一响应体格式），Content-Type 为 `text/plain`。


##### 错误响应

无（静态欢迎页，不会返回错误）。

### 2 新增首页欢迎接口 <span style="color:green">**[新增]**</span>

| 属性 | 值 |
|------|-----|
| **请求方式** | `GET` |
| **接口路径** | `/new` |
| **接口说明** | 新增的测试接口，返回包含应用名称的欢迎字符串。不经过统一响应体包装，直接返回纯文本。 |
| **认证方式** | 无需认证（类级 `@SaIgnore`） |
| **权限要求** | 无 |
| **标签** | 首页 |
| **变更类型** | `added` |

---

#### 变更说明

在 `IndexController` 中新增 `GET /new` 端点，与已有的 `GET /` 类似，返回纯文本字符串而非 JSON 统一响应体格式。类级 `@SaIgnore` 注解使该端点无需认证即可访问。

**源码**:

```java
@GetMapping("/new")
public String hello() {
    return StringUtils.format("{} 新增接口", SpringUtils.getApplicationName());
}
```

---

#### 请求

**请求头**: [公开]

无请求参数。

---

#### 响应

##### 成功响应 — HTTP 200

返回纯文本字符串，Content-Type 为 `text/plain`。不经过 `R<T>` 统一包装。

```
RuoYi-Vue-Plus 新增接口
```

##### 错误响应

无。
